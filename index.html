How this page works

On load, this page tells Google's tags "assume the visitor has NOT consented to analytics or ad tracking" — before the GTM container even finishes loading. This is called setting consent defaults.

When you click Accept or Decline below, the page updates that consent state in real time using gtag('consent', 'update', ...). GTM and GA4 read this signal automatically — no manual tag-by-tag gating required for standard Google tags.

Try clicking the CTA button above before responding to the banner, then again after accepting — and compare what GTM Preview shows each time.
